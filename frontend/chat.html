Assistant Widget dev harness

Widget development only — the application UI is ui/ (http://localhost:5174). Fill in a dev access token (see README.md → "Local Keycloak development setup" for how to obtain one via curl) and click Load widget to mount <assistant-widget> against the running backend. Attributes are only read once when the element is created, so the widget is re-created from scratch on every click rather than having its attributes updated in place.

Never commit a real token — this field is intentionally left empty by default.
